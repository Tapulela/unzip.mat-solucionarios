# Parciales — Matemática 1 (AUSC-PUC-LSI)

Exámenes parciales, ordenados por tipo y, dentro de cada tipo, del más nuevo al más
viejo. Cada examen tiene su carpeta con:

- `consigna.png` (o `.jpg`, `.pdf`): la foto o el archivo del examen tal como se tomó,
  como registro documental. **Todo examen resuelto lleva su consigna.**
- `solucion.json`: la resolución (formato `unzip.mat/solucion@1`, ver
  [FORMATO.md](../../../../FORMATO.md)), si ya está resuelto.

Los nombres de las carpetas siguen el patrón
`<año> - cuatrimestre <n> - parcial <1|2> <tipo>[ - <variante>]`, con la variante
cuando hace falta (`ingresantes - fila 1`, `recursantes - fila 2`, `recuperatorio`). Un
parcial se toma después de la fecha del examen, nunca antes.
